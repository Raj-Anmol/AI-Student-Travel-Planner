# 🎒 Smart Student Budget Travel Planner 🚌

An advanced, interactive, and user-friendly web application built using **Streamlit** that helps college students plan their budget trips efficiently. It analyzes dynamic inputs like budget constraints and trip duration to automatically tailor smart accommodation, food, transport options, and a day-by-day itinerary without requiring complex third-party APIs.

---

## 🚀 Key Features

- **📊 Dynamic Expense Breakdown:** Automatically calculates and displays budget allocations for Stay, Food, Transport, and Emergency buffers based on student friendly rates.
- **🗺️ Tailored Day-by-Day Itinerary:** Provides realistic morning, afternoon, and evening activities tailored perfectly to the total trip duration.
- **🧳 Smart Packing Checklist:** Features an interactive checklist that dynamically updates items depending on the destination (e.g., automatically suggests warm clothes for mountain trips or sunscreen for beaches).
- **🚨 Interactive Safety Dashboard:** Includes built-in national emergency contacts, split-cash tips, and digital identity management guides for students.

---

## 🛠️ Tech Stack & Concepts Used

- **Frontend UI:** Streamlit (Python-based interactive web framework)
- **Data Engineering:** Pandas DataFrames (for structuring expense data tables)
- **Deployment & Tunneling:** Ngrok Tunneling (making a local server accessible live globally)
- **Algorithmic Logic:** Rule-Based AI Engine for pocket-friendly travel distribution.
